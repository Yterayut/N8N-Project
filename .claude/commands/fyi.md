# FYI — Quick Memory Log

Log a piece of information to persistent memory immediately, without ceremony.

## Usage
```
/fyi <information to remember>
```

## What To Do

1. Read the user's message after `/fyi` — that is the information to log
2. Read `memory/MEMORY.md` to find the most relevant section
3. Append or update the relevant section with the new information
   - If it fits an existing section: edit that section
   - If it's new: add a short new bullet under the most relevant heading
   - If no section fits: add a new `## <topic>` heading
4. Keep it concise — one bullet line when possible
5. Confirm: "Logged to MEMORY.md: `<what was saved>`"

## Rules
- Do NOT overwrite or delete existing memory entries
- Do NOT create a new heading if an existing one fits
- Do NOT ask clarifying questions — just log it and confirm
- If the info contradicts existing memory, update the old entry and note the change
